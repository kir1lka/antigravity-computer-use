# Computer Use (`cu.py`) — Complete Reference

Script location: `C:\Users\PC\.gemini\config\skills\computer-use\scripts\cu.py`
Native UIA scanner: `C:\Users\PC\.gemini\config\skills\computer-use\scripts\uia_scan.exe` (auto-rebuilt from `uia_scan.cs` via built-in .NET `csc.exe` if missing).
Cache directory: `%TEMP%\cu_cache\` (`screen.jpg`, `som.jpg`, `last_som.json`).

---

## Coordinate Systems

1. **Normalized `0..1000` (Default)**
   - `(0, 0)` = top-left of primary monitor; `(1000, 1000)` = bottom-right.
   - Automatically mapped to exact physical pixels (Per-Monitor DPI v2 aware — works cleanly at 100%, 125%, 150%, 200%, 4K).
2. **Set-of-Mark IDs (`--id N`)**
   - Generated by `python cu.py som` and cached in `%TEMP%\cu_cache\last_som.json`.
   - Supported by `click`, `rclick`, `dclick`, `move`, `scroll`, `type`, `paste`, and `batch` (`#12` or `id=12` or `{"id": 12}`).
3. **Physical Pixels (`--px`)**
   - Pass `--px` on any coordinate command to pass raw physical pixel coordinates directly.

## Subcommands

### Observation
- `state` — Instant JSON: `screen`, `virtual_screen`, `cursor_norm`, `cursor_px`, `active_window`, `clipboard_preview`.
- `shot [-o path] [--grid] [--cursor] [--window] [--hwnd H] [--crop X Y W H] [--px] [--all-screens] [--width 1280] [--quality 85]`
- `som [--hwnd H] [--desktop] [--max 80] [--depth 10] [--text] [--width 1280] [-o path] [--no-image]`
- `find-img <template_path> [--threshold 0.85] [--click | --dclick | --rclick]`
- `wait-change [--timeout 10] [--interval 0.15] [--threshold 2.5] [--region X Y W H] [--px] [--shot]`

### Mouse
- `click [X Y | --id N] [--button left|right|middle] [--clicks 1|2|3] [--smooth] [--px] [--shot|--som]`
- `rclick [X Y | --id N] [--smooth] [--px] [--shot|--som]`
- `dclick [X Y | --id N] [--smooth] [--px] [--shot|--som]`
- `move [X Y | --id N] [--smooth] [--duration 0.14] [--px]`
- `down [left|right|middle]` / `up [left|right|middle]`
- `drag X1 Y1 X2 Y2 [--button left] [--duration 0.25] [--px] [--shot]`
- `scroll AMOUNT [X Y | --id N] [--horiz] [--px] [--shot]` (positive = up/right, negative = down/left)

### Keyboard & Clipboard
- `type "text" [--id N | --x X --y Y] [--clear] [--enter] [--delay 0.004] [--shot]`
  - Uses `KEYEVENTF_UNICODE` (UTF-16 surrogate pairs supported). Works for Russian, English, symbols, and emoji regardless of active Windows keyboard layout.
- `paste "text" [--id N | --x X --y Y] [--clear] [--enter] [--restore] [--shot]`
  - Writes UTF-16 directly to Win32 clipboard (`CF_UNICODETEXT`) and sends hardware VK `Ctrl+V` (works in EN and RU keyboard layouts).
- `key <name> [--count 1] [--delay 0.03] [--shot]`
- `hotkey <combo> [--shot]` (e.g. `ctrl+c`, `ctrl+shift+esc`, `alt+tab`, `win+d`, `win+r`, `ctrl+l`)
- `clipboard get` / `clipboard set "text"`

### Windows & Apps
- `windows [--filter query]` — Lists visible top-level windows with HWND, PID, exe, title, state, active flag, pixel & norm rects.
- `focus <title_or_exe_or_hwnd> [--shot|--som]` — Restores minimized window and brings to foreground using `AttachThreadInput` + Alt pulse.
- `winop <target> <max|min|restore|close|move> [X Y W H] [--px]`
- `launch <target> [--args "..."]` — Detached start via `os.startfile` or `DETACHED_PROCESS`.

## Batch Mode (`batch`)

### Inline Shorthand Syntax
```powershell
python $CU batch "focus:Chrome" "wait:0.15" "hotkey:ctrl+l" "paste:https://github.com" "key:enter" "wait-change:8" "shot:grid"
```
Supported inline ops:
- `click:X,Y` or `click:#12` (`rclick:`, `dclick:`, `move:`)
- `drag:X1,Y1,X2,Y2`
- `scroll:-5` or `scroll:-5,500,500` (`hscroll:`)
- `type:text` / `paste:text`
- `key:enter` / `hotkey:ctrl+s`
- `wait:0.3` / `wait-change:8`
- `focus:AppName` / `launch:notepad`
- `shot` / `shot:grid` / `shot:window` / `som` / `som:desktop`

### JSON Batch Syntax (Best for Complex Text with Colons/Quotes)
```powershell
python $CU batch --json '[{"op":"focus","target":"Notepad"},{"op":"paste","text":"URL: https://example.com\nСтрока 2","clear":true,"enter":true},{"op":"wait","sec":0.2},{"op":"shot","grid":true}]'
```

## Supported Key Names

- Letters & digits: `a`-`z`, `0`-`9`
- Function keys: `f1`-`f24`
- Modifiers: `ctrl` (`lctrl`, `rctrl`), `alt` (`lalt`, `ralt`), `shift` (`lshift`, `rshift`), `win` (`lwin`, `rwin`, `super`)
- Navigation: `enter`, `tab`, `esc`, `space`, `backspace`, `delete`, `insert`, `home`, `end`, `pgup`, `pgdn`, `up`, `down`, `left`, `right`
- System/Media: `printscreen`, `capslock`, `numlock`, `apps`, `mute`, `voldown`, `volup`, `media_play`, `media_next`, `media_prev`, `media_stop`
- Punctuation: `-`, `=`, `[`, `]`, `;`, `'`, `,`, `.`, `/`, `\`, `` ` ``

## Troubleshooting

- **Screen capture fails (`ImageGrab` / `BitBlt`)**: Windows workstation is locked, a UAC secure desktop is active, or the shell is running in a non-interactive/sandboxed session without desktop access.
- **Hotkeys don't trigger in an elevated (Admin) window**: Windows UIPI blocks `SendInput` from a standard user process into an Administrator window. The user must interact with elevated windows directly or run the session elevated.
- **`som` finds 0 elements**: Some apps (DirectX/Vulkan games, custom canvases, remote desktop streams) don't expose a Windows UIA tree. Fall back to `shot --grid`, `shot --crop ... --grid`, or `find-img`.
